Google Drive Sync Setup

This app can save your data to a JSON file in your Google Drive so it's accessible from any computer. To enable this, you need a Google Drive API key.

  1. Go to Google Cloud Console → Create a project
  2. Enable the Google Drive API for the project
  3. Go to Credentials → Create API Key
  4. Also create an OAuth 2.0 Client ID (Web application type), add http://localhost and your file's location to Authorized Origins
  5. Paste the Client ID below and click Connect

Simpler alternative: Use the Import / Export buttons to manually back up and restore your data as a JSON file. Save it to your Google Drive folder manually — works perfectly across computers without any API setup.
